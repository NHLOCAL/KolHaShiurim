# מדריך למשתמש: קול השיעורים

המדריך מיועד למנהלי מערכת קול השיעורים ולמשתמשים המעבירים הקלטות. התוכנה מקומית, פועלת ב-Windows 10/11 x64 ואינה דורשת הפעלת רישיון או אימות חומרה. עדיין יש להגדיר משתמשים, התקנים והרשאות ליעדי ההעברה.

## פרק 1: התקנה והפעלה ראשונה

התקינו את התוכנה באמצעות קובץ ההתקנה, או חלצו את כל תוכן חבילת ה-ZIP הניידת והפעילו את `kol_hashiurim.exe`. פאנל הניהול נפתח בהפעלה רגילה. אפשר לפתוח אותו שוב מסמל התוכנה באזור ההתראות באמצעות **פתח פאנל ניהול**.

לאחר הגדרת המערכת, **סגרו את חלון פאנל הניהול** באמצעות כפתור הסגירה של Windows. התוכנה תמשיך לפעול באזור ההתראות ותחדש את ניטור התקני ההקלטה. כל עוד פאנל הניהול פתוח, ניטור ההתקנים נעצר והממשק למשתמש אינו נפתח אוטומטית. בתפריט הסמל, **יציאה** מסיימת את התוכנה.

## פרק 2: היכרות עם פאנל הניהול

בפאנל חמש לשוניות:

* **משתמשים:** יצירה ועריכה של משתמשים והגדרת הרשאות ההעברה שלהם.
* **רבנים:** הגדרת שמות הרבנים ותיקיות היעד במחשב.
* **התקנים:** שיוך התקן הקלטה למשתמש והגדרת תיקיית המקור.
* **הגדרות:** המרה ל-MP3, גיבוי ושחזור.
* **אודות:** מידע על התוכנה ופרטי יצירת קשר.

## פרק 3: הגדרת המערכת בארבעה צעדים

### 3.1 הגדרת רבנים ותיקיות יעד

כל רב מקבל תיקיית יעד משלו במחשב המרכזי. ודאו שלחשבון Windows המפעיל את התוכנה יש הרשאת כתיבה לתיקיות היעד.

1. עברו ללשונית **רבנים** ולחצו **הוסף רב**.
2. בחלון **הוספת רב חדש**, הזינו **שם הרב** ו**נתיב יעד (במחשב)**. אפשר להקליד נתיב או לבחור תיקייה.
3. לחצו **שמירה**. חזרו על הפעולה עבור כל רב.

### 3.2 יצירת משתמשים

1. עברו ללשונית **משתמשים** ולחצו **הוסף משתמש**.
2. הזינו **שם משתמש**. בשדה **פרטים נוספים (טלפון, שיעור, ועד וכו')** אפשר להוסיף מידע לפי הצורך.
3. לחצו **שמירה** וחזרו על הפעולה עבור כל משתמש.

### 3.3 רישום התקנים

רשמו את התקן ההקלטה הפיזי של המשתמש ואת התיקייה שבה נמצאות ההקלטות.

1. חברו את ההתקן למחשב.
2. עברו ללשונית **התקנים** ולחצו **הוסף התקן**.
3. בחלון **הוספת התקן חדש**, לחצו **אתר התקן ובחר תיקיית מקור**.
4. בחרו תיקייה בהתקן, למשל `RECORDS` או `VOICE`. אם הקבצים בשורש הכונן, בחרו את הכונן עצמו.
5. התוכנה תמלא **מספר סידורי** ו**נתיב מקור (יחסית לכונן)**. ודאו שהנתיב מצביע לתיקיית ההקלטות הנכונה.
6. בשדה **משתמש משוייך**, בחרו את המשתמש הרצוי ולחצו **שמירה**.

**שינוי מספר סידורי הוא אפשרות נפרדת.** אם הוא נחוץ, הורידו בעצמכם את [VolumeID מאתר Microsoft](https://learn.microsoft.com/en-us/sysinternals/downloads/volumeid), קראו וקבלו את תנאיו, והציבו את `Volumeid.exe` לצד קובץ ההפעלה או בתיקייה ב-PATH. הכלי אינו כלול בתוכנה או במתקין. הזינו מספר בן שמונה ספרות הקסדצימליות, למשל `1234-ABCD`, ולחצו **החלף מספר סידורי בהתקן**. ייתכן שיידרשו הרשאות מנהל. לאחר שינוי מוצלח נתקו וחברו מחדש את ההתקן. אין צורך בכלי כדי לרשום התקן שמספרו כבר מתאים.

### 3.4 מתן הרשאות

1. חזרו ללשונית **משתמשים** ולחצו **הרשאות** בשורת המשתמש.
2. בחלון **עריכת הרשאות**, סמנו את הרבנים שאליהם המשתמש רשאי להעביר שיעורים.
3. להגבלה לתיקיות משנה בתוך תיקיית הרב, לחצו **הוסף הגבלת תיקיה** והגדירו את הנתיבים הרצויים. אם הוגדרו כמה נתיבים, המשתמש יבחר ביניהם בעת ההעברה. ללא הגבלה, אפשר להעביר לתיקייה הראשית של הרב.
4. לחצו **שמור**. חזרו עבור כל משתמש.

בסיום ההגדרה סגרו את חלון פאנל הניהול כדי שהניטור האוטומטי יחזור לפעול.

## פרק 4: העברת שיעור

1. המשתמש מחבר את ההתקן הרשום שלו. כשהתוכנה פועלת ברקע ופאנל הניהול סגור, הממשק נפתח אוטומטית במסך מלא.
2. בחרו קובץ שמע מתוך רשימת הקבצים בתיקיית המקור. אפשר להאזין לקובץ כדי לוודא שזהו השיעור הרצוי.
3. בחרו רב מתוך רשימת היעדים המורשים. אם הוגדרו כמה תיקיות משנה, בחרו את תיקיית המשנה הרצויה.
4. בדקו את התאריך העברי שמולא אוטומטית ושנו אותו אם צריך. אפשר להוסיף נושא לשיעור באמצעות המקלדת שעל המסך.
5. לחצו **העתק את השיעור**. התוכנה נותנת לקובץ שם ומספר עוקב בתיקיית היעד.
6. לאחר הצלחת ההעתקה בחרו אם למחוק את קובץ המקור מההתקן. המחיקה היא פעולה נפרדת לבחירת המשתמש.
7. נתקו את ההתקן בסיום. ממשק המשתמש ייסגר.

## פרק 5: הגדרות מתקדמות ונתונים

* **המרה ל-MP3:** בלשונית **הגדרות** אפשר להפעיל המרה ולבחור Bitrate. לשם כך יש להתקין `ffmpeg` בנפרד ולהוסיף אותו ל-PATH. ללא המרה אין צורך ב-FFmpeg.
* **גיבוי:** בלשונית **הגדרות**, בחרו **גיבוי הגדרות והרשאות** ושמרו קובץ JSON. גבו לפני מעבר מחשב או שינויים משמעותיים.
* **שחזור:** בלשונית **הגדרות** אפשר לטעון קובץ JSON. השחזור מחליף את המשתמשים, הרבנים, ההתקנים, ההרשאות וההגדרות הקיימים. גבו תחילה את המצב הנוכחי.

מסד הנתונים המקומי נשמר בתיקיית Documents של המשתמש בקובץ `kol_hashiurim.sqlite`. בשדרוג מגרסה ישנה, התוכנה ממשיכה להשתמש בקובץ `torah_shiurim.sqlite` אם אין קובץ בשם החדש, ומשמרת את הנתונים הקיימים. אם שני הקבצים קיימים, הקובץ החדש מקבל קדימות ואין מיזוג אוטומטי. יומן הפעולות נמצא בתיקיית התמיכה של האפליקציה תחת `logs/app_log.txt`. קובצי גיבוי ויומן עשויים להכיל שמות ונתיבים. שמרו אותם באופן פרטי ואל תצרפו אותם לדיווח ציבורי ללא בדיקה והשחרה.
