# מדריך שימוש: קול השיעורים

קול השיעורים מאפשרת למנהל להגדיר משתמשים, התקני הקלטה, רבנים ותיקיות יעד. משתמש שמחבר התקן רשום יכול להעביר הקלטות רק ליעדים שהוגדרו עבורו. התוכנה אינה דורשת הפעלת רישיון.

## התקנה והפעלה ראשונה

התקינו את גרסת Windows 10/11 x64 באמצעות קובץ ההתקנה, או חלצו את כל תוכן חבילת ה-ZIP הניידת והפעילו את `kol_hashiurim.exe`. פתחו את פאנל הניהול מסמל התוכנה באזור ההתראות. יש לוודא שלחשבון Windows המפעיל את התוכנה יש הרשאת כתיבה לתיקיות היעד.

## הגדרת המערכת

1. בלשונית **רבנים**, הוסיפו לכל רב שם ותיקיית יעד במחשב.
2. בלשונית **משתמשים**, הוסיפו את האנשים המורשים להעביר שיעורים.
3. חברו התקן הקלטה. בלשונית **התקנים**, בחרו **הוסף התקן**, ואז **אתר התקן ובחר תיקיית מקור**. בחרו תיקייה כגון `RECORDS`, או את שורש הכונן אם ההקלטות נמצאות בו. התוכנה מזהה את מספר הכונן וממלאת את נתיב המקור היחסי. שייכו את ההתקן למשתמש ושמרו.
4. בלשונית **משתמשים**, פתחו **הרשאות** למשתמש וסמנו את הרבנים שאליהם הוא רשאי להעביר. אפשר להגדיר תיקיות משנה מורשות בתוך תיקיית הרב. שמרו את ההרשאות.

אם יש צורך לשנות מספר סריאלי של כונן, הורידו בעצמכם את [VolumeID מאתר Microsoft](https://learn.microsoft.com/en-us/sysinternals/downloads/volumeid), קראו את תנאיו והציבו את `Volumeid.exe` לצד קובץ התוכנה או ב-PATH. הכלי אינו נכלל בהתקנה, ואינו נדרש לרישום התקן שכבר יש לו מספר מתאים. שינוי מספר הכונן עשוי לדרוש חיבור מחדש של ההתקן.

## העברת שיעור

חברו התקן רשום. הממשק נפתח כאשר התוכנה מזהה אותו. בחרו קובץ שמע מתוך תיקיית המקור, והאזינו לו לפי הצורך. בחרו רב מורשה, תיקיית משנה אם הוגדרה, תאריך עברי ונושא לפי הצורך. לחצו על כפתור ההעתקה. התוכנה יוצרת שם ומספר עוקב בתיקיית היעד; לאחר הצלחה אפשר לבחור אם למחוק את קובץ המקור. בניתוק ההתקן הממשק נסגר.

## המרה, גיבוי ונתונים

בלשונית **הגדרות** אפשר להפעיל המרה ל-MP3 ולבחור איכות. המרה דורשת התקנת `ffmpeg` בנפרד והוספתו ל-PATH. ללא המרה, אין צורך ב-FFmpeg.

באותה לשונית אפשר לייצא את ההגדרות לקובץ JSON ולשחזר אותן. השחזור מחליף את ההגדרות הקיימות, ולכן גבו אותן לפני השחזור. מסד הנתונים המקומי נמצא בתיקיית Documents של המשתמש בקובץ `kol_hashiurim.sqlite`. יומן הפעולות נמצא בתיקיית התמיכה של האפליקציה, תחת `logs/app_log.txt`. קובצי הגיבוי והיומן עשויים להכיל שמות ונתיבים; שמרו אותם באופן פרטי ואל תצרפו אותם לדיווח ציבורי.
